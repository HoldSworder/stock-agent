# 过热衰竭修正主线龙头

从 `etf-mainline-factor-sweep` 中抽取的高收益模式：以 `anti_exhaustion_score` 排序，每 3 个交易日检查一次，只持有全池最强 1 个 ETF；退出规则为跌破 MA120 或跌出加权 Top1，不做周期性权重重置。

## 推荐候选

推荐配置：`anti-leader|anti_exhaustion_score|above60|3d|100%`

买卖规则：

- ETF 池沿用主线研究池 55 只；
- 入场：满足 `above60`，按 `anti_exhaustion_score` 排名取 Top1；
- 调仓：每 3 个交易日检查一次；
- 退出：跌出加权 Top1，或跌破 MA120；
- 仓位：单腿 100%，最大持仓 1，天然不超过最大持仓 3；
- 成交验证：同时输出收盘成交与次开 + 10bp 成本口径。

## 重要风险

- 该模式为单腿龙头模式，收益高度集中在通信、半导体设备、全球芯片、卫星等少数主线。
- `anti_exhaustion_score` 仍是 ETF 自身 K 线因子，不能替代板块宽度、成分股新高、ETF 份额变化等主线确认。
- 回测区间为 2025-01-02 至 2026-06-26，仍需前向跟踪验证。
- 3 日调仓对成交质量敏感，实盘应使用次开/滑点口径评估。
