# 风控过滤黏性主线龙头

黏性过热衰竭主线龙头的风控版。加入市场状态过滤，弱市场允许空仓，用一部分收益换取更低回撤。

## 推荐候选

推荐配置：`risk-gated-sticky|anti_exhaustion_score|above60|3d|min6|sw0.04|top2|soft-risk`

买卖规则：

- ETF 池沿用主线研究池 55 只；
- 入场：满足 `above60`，按 `anti_exhaustion_score` 排名取 Top1；
- 市场过滤：`benchmark_risk_on > 0` 或 ETF 自身 `mom30 > 8%`，否则空仓；
- 调仓：每 3 个交易日检查一次；
- 黏性规则：最小持有 6 个交易日；
- 强者替换：新标的分数至少高出当前持仓 0.04 才替换；
- 退出：市场过滤转弱、跌破 MA120、持仓跌出 Top2；
- 仓位：单腿 100%，市场弱时空仓，最大持仓 1。

## 重要风险

- 市场过滤会空仓，可能错过部分突然启动的强主线。
- 该模式收益低于进攻版，但回撤从约 -23.6% 降至约 -20.3%。
- 仍是单腿模式，需配合前向跟踪和主线宽度确认。
