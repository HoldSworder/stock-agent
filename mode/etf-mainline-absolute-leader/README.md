## 推荐候选

`wrot-keep|mom90|noabs|85%/15%|ma120`

含义:

- 不使用 RS，不看相对沪深300强弱。
- 主线判断只用 ETF 自身 90 日绝对涨幅 `mom90`。
- 同主题最多 1 只。
- 只持有 Top2，权重 85% / 15%，最大持仓数为 2，满足“持仓最大为 3”。
- 每 5 个交易日检查一次；跌出加权 Top2 切换。
- 额外保留 MA120 趋势退出口径。
