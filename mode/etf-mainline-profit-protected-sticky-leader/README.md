# 盈利保护黏性主线龙头

在“黏性过热衰竭主线龙头”基础上加入盈利保护退出层。核心思路不是更频繁择时，而是在原本每 3 个交易日的持仓复核点检查：如果单笔持仓曾经浮盈超过 25%，随后从持仓峰值回撤 8%，则先锁定主升收益。

这是当前黏性主线龙头的收益升级版。它提高收益和次开成本口径表现，但收盘口径最大回撤仍与原模式接近，不应误读为低回撤模式。

## 推荐候选

推荐配置：`profit-protected-sticky|anti_exhaustion_score|above60|3d|min4|sw0.035|top2|pg25%|dd8%`

买卖规则：

- ETF 池沿用主线研究池 55 只；
- 入场：满足 `above60`，按 `anti_exhaustion_score` 排名取 Top1；
- 调仓：每 3 个交易日检查一次；
- 黏性规则：最小持有 4 个交易日；
- 强者替换：新标的分数至少高出当前持仓 0.035 才替换；
- 常规退出：跌破 MA120，或持仓跌出 Top2；
- 盈利保护：单笔持仓浮盈超过 25% 后，如从持仓峰值回撤 8%，在复核点退出；
- 仓位：单腿 100%，最大持仓 1，天然不超过最大持仓 3；
- 同主题约束：单腿持仓不会同时买入港股创新药与港股创新药(广发)等同主题重复标的；
- 成交验证：重点看次开 + 10bp 成本口径。

## 稳健性复查

围绕推荐参数做局部精扫后，`min_hold=4~6`、`switch_margin=0.035~0.050`、`protect_gain=25%~30%`、`protect_dd=8%` 的多组相邻参数均得到同一组核心结果：收盘 `+635.8%`、最大回撤 `-23.6%`、次开 10bp `+571.2%`。这说明收益提升不是单点尖峰。

一个重要反例：如果把盈利保护改成每日检查，结果降至收盘约 `+550.2%`、次开 10bp 约 `+511.3%`，低于原黏性基准。说明该规则只能作为中低频复核层，不能变成日频追踪止盈。

## 重要风险

- 该模式仍是单腿龙头模式，收益高度集中在全球芯片、半导体设备、通信、卫星等少数主线标的。
- 盈利保护会提前兑现部分强趋势，若主线只是正常震荡，可能被洗出后再追高买回。
- 回测区间为 2025-01-02 至 2026-06-26，需要继续前向跟踪。
- 因子仍主要来自 ETF 自身 K 线，实盘应结合板块宽度、成分新高、成交额跃迁和资金流确认。
