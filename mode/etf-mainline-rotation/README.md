# ETF 主线轮动模式（MACD金叉/追涨 + RS动量门禁 + Supertrend 出场）

这是一次独立归档的 ETF 交易模式研究包。完整策略逻辑与回测方法的权威文档仍保留在 `docs/`：

- `docs/etf-mainline-rotation-strategy.md` —— 本模式的可执行规则 + 回测方法（权威版）
- `docs/etf-trend-strategy-blueprint.md` —— 分层理念、RS/宽度/跌停潮取舍论证

## 推荐模式

```text
主线门禁挑赛道 → 金叉/追涨择时进场 → Supertrend 咬住整波 → RS 更强的新主线自动轮换
基准池：ETF 模块完整跟踪池（/api/etf/pool，55 只）
门禁(碰不碰)：收盘 > MA60 且 RS ≥ 自身60日RS高 × 0.97
进场(何时买)：(日线MACD金叉 或 追涨) 且 RS动量 ≥ 0.03（领先且在加速）
选择(买哪只)：合格候选里 RS动量 最强补空位（必须用 RS 变化率，不能用 RS 绝对值）
出场(何时卖)：Supertrend(10,3) 翻空（唯一清仓信号）
轮换(换不换)：满仓时 候选RS动量 > 最弱持仓 + 0.05 且持有≥5日 → 砍弱换强
仓位：等权 N 只，无合格候选则该格留现金（可阶段性空仓）
```

> 100% 机械：每笔买/卖/轮换都是确定性指标规则，无人工/AI 判断，对应蓝本的「机械核心」。实盘会在其上再叠加预警层（跌停潮/背离 → 收紧止损、减半仓），未纳入本回测。

## 核心结果

区间 2025-01-02 → 2026-06-26｜完整跟踪池55｜a-stock-data mootdx_kline + 份额折算前复权：

| 配置 | 总收益 | 年化 | 最大回撤 | 交易 |
|---|---:|---:|---:|---:|
| 满仓 2 只 | +190% | +107% | -24% | 128 |
| 满仓 3 只 | +178% | +101% | -22% | 183 |
| 3只各28%(留16%现金) | +145% | +85% | -19% | 183 |
| 3只各25%(留25%现金) | +125% | +74% | -18% | 183 |
| 3只各22%(留34%现金) | +106% | +64% | -16% | 183 |
| 满仓 1 只 | +172% | +98% | -35% | 73 |

同期宽基躺平：科创50 +111%/-19%、创业板指 +109%/-21%、沪深300 +26%/-10%。
**抓真主线 ⇄ 大回撤焊死**，收益与回撤近似线性绑定，按可承受回撤选档。

## 复现

从项目根目录运行（K线源 a-stock-data 不需鉴权，有内置 55 只跟踪池兜底）：

```bash
python3 mode/etf-mainline-rotation/etf-rotation-backtest.py
```

把交易记录直接写回本模式包：

```bash
SA_TRADE_LOG=mode/etf-mainline-rotation/backtest-data/trades_pool.md \
python3 mode/etf-mainline-rotation/etf-rotation-backtest.py
```

可选环境变量（均有默认）：

| 变量 | 默认 | 说明 |
|---|---|---|
| `SA_HOST` | `192.168.31.144` | NAS 局域网 IP（a-stock-data:9119 与可选的 /api/etf/pool） |
| `SA_ASTOCK` | `http://$SA_HOST:9119` | a-stock-data 基址 |
| `SA_APP_TOKEN` | 空 | 填了则实时拉取「我的跟踪池」，否则用内置 55 只清单兜底 |
| `SA_CACHE` | `/tmp/klcache` | K线缓存目录，删掉即强制重抓 |
| `SA_TRADE_LOG` | `/tmp/trades_pool.md` | 交易记录输出路径 |
| `SA_SWEEP` | 空 | `=1` 额外跑参数扫描 Top20 |

## 重要风险

- **样本是两个超级趋势年**：2025/2026 是 A 股罕见连续主升，+100% 量级年化是「强行情 + 强赛道池」叠出来的，不是常态。
- **份额折算复权（回测已修，生产待修）**：mootdx 原始数据 / NAS `/api/kline` 都对 ETF 份额折算不复权，折算日有假 −50% 断崖。回测已加「单日跌幅>35%即折算前复权」修掉；**生产盯盘/指标在折算标的上仍受影响，待补同样的复权。**
- **横向排名必须用 RS 变化率**：`RS = ETF价 ÷ 沪深300价` 受名义份额单价主导，低价但最强的主线（通信/半导体设备）会被 RS 绝对值系统性排除——必须用 RS动量（默认20日，门槛≥0.03）。
- **同族相关性风险**：横向排名可能同时选入光伏/电池/储能或两格电网等高相关品种，被同一波回调一起 ST 放大回撤（见 2025-11、2026-03）。跟踪池重复标的多会加重，建议清理重复 + 后续加同族去重。
- **浮盈占比 / 多腿捕获打折**：满仓档收益含相当部分期末未实现浮盈；锯齿磨涨板块会被 ST 反复洗，吃不满整波。
