# 执行确认共识主线龙头

在“过热衰竭修正主线龙头”的基础上，加入跳空动量与 PVT 量价确认，用三个冠军因子的横截面排名均值形成 `execution_consensus_score`。目标不是追求最高收盘收益，而是改善次开 + 成本口径。

## 推荐候选

推荐配置：`exec-consensus|execution_consensus_score|above60|3d|100%`

买卖规则：

- ETF 池沿用主线研究池 55 只；
- 入场：满足 `above60`，按 `execution_consensus_score` 排名取 Top1；
- 共识分数：`rank(anti_exhaustion_score, gap_momentum_score, pvt_confirm_score)` 的均值；
- 调仓：每 3 个交易日检查一次；
- 退出：跌出加权 Top1，或跌破 MA120；
- 仓位：单腿 100%，最大持仓 1，天然不超过最大持仓 3；
- 成交验证：重点看次开 + 10bp 成本口径。

## 重要风险

- 该模式仍是单腿龙头模式，收益集中在少数主线，不能替代组合风控。
- 收盘收益略低于 `anti_exhaustion_score`，优势主要体现在次开 + 成本口径。
- 共识分数来自 ETF 自身 K 线和量价指标，仍需板块宽度、成分新高、ETF 份额变化做前向确认。
