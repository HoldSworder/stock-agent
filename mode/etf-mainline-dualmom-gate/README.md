# ETF 主线双动量·哨兵降仓模式

独立归档的 ETF 交易模式研究包。它**不追求更高收益**，而是补 `etf-mainline-leader-runner` / RS90 的命门——**没有 regime 开关**：RS90 在 2024 无主线年被迫死扛"最不烂的板块"，全年 +7% 却吃 −30% 回撤，9月急反转里市场暴涨它反而亏。本模式照搬已被多市场、数十年样本外验证的 **Dual Momentum（Antonacci GEM）/ Keller VAA** 思想，只做"参数极少 + 有经济逻辑"的迁移，给系统加一层**确定性的降仓哨兵**。底座（55 池、a-stock-data、份额折算复权、同主题去重）不变。

## 模式规则

```text
排名口径：13612W 混合动量 = 12·(p0/p1−1) + 4·(p0/p3−1) + 2·(p0/p6−1) + 1·(p0/p12−1)
          （月数=21/63/126/252 交易日；近月权重大，替代 RS90 单一90日窗口，多周期更不脆）
哨兵开关：沪深300 的 13612W > 0 → 进攻；≤0 → 整仓撤到防御资产（GEM 式绝对动量）
进攻持仓：哨兵 ON 时，按 13612W 选最强 N 只板块（同主题去重，等权），仅买 13612W>0 的
防御资产：{十年国债511260, 黄金518880, 货币511990} 里 13612W 最强的一只（货币≈现金底）
调仓节奏：月频（这类框架都是月频，低换手、抗 whipsaw、省成本）
推荐 N=3
```

## 核心结果（2024-04 → 2026-06，数据需 252 日预热故从 2024-04 起）

| 窗口 | 本模式 canary N3 | 永远满仓对照 none N3 | 指数躺平 |
|---|---|---|---|
| **2024 无主线磨底(4–9月)** | **+4% / −9%** | −16% / −24% | 沪深300 −9% / 科创50 −17% |
| **2024 无主线+反转(4–12月)** | **+6% / −13%** | −14% / −28% | 沪深300 +12% / 科创50 +29% |
| 2025-26 主升 | +112% / −21% | +175% / −22% | 科创50 +111% |
| 全段 2024.04–2026.06 | +114% / **−27%** | +127% / −28% | 科创50 **+162% / −19%** |

> 一句话：**它把 2024 无主线年的回撤从 −28% 砍到 −13%、把亏损翻成正收益**，代价是牛市少赚（少赚约 1/3）。

## 这次调研的三个诚实结论

1. **逐板块绝对动量门（breadth）对 A股行业ETF 失效。** 回测里 `breadth` 与 `none`（永远满仓）数字几乎完全一样——A股行业高相关，无主线时仍总能找到 3 个 13612W>0 的板块（离岸科技/黄金等），逐资产的门几乎不触发。**这是一个被证伪的方向，已记录避免重复踩。**
2. **真正有效的是 GEM 式"大盘哨兵"（canary）**：用沪深300 整体动量当总开关，无主线时整仓撤防御。这是唯一在 2024 真正降了仓、把回撤腰斩的机制。它只有"**1 个核心参数（大盘动量符号）**"，正是 Dual Momentum 几乎不可能过拟合的原因。
3. **它是风险控制覆盖层，不是收益放大器。** 本回测样本被超级牛（科创50 全段 +162%）主导，**连指数躺平的总收益都难被超越**——所以别拿它和 leader-runner 比总收益。它的价值是无主线年的回撤保护与"不在烂行情里硬扛"。

## 建议用法（与 leader-runner 组合）

这套哨兵最佳用法不是单独运行，而是**当 leader-runner 的 regime 总开关**：

- 沪深300 13612W > 0（且你系统的板块新高宽度确认有主线）→ 放 `leader-runner` 的进攻集中档，把主升浪榨满；
- 哨兵 ≤ 0 / 宽度说无主线 → 整仓撤到国债/黄金，停掉进攻。

如此把 leader-runner 的"主升浪上限"与本模式的"无主线降仓"合一，得到一条全年纪律完整、不在烂行情里硬扛的曲线。这也契合你"agent 主导判断 + 确定性硬护栏"的设计路线——**哨兵就是那道确定性护栏**。

## 重要风险

- **样本短且被超级牛主导**：2024-04 起才有完整 13612W，且 2025-26 是罕见连续主升；canary 少赚的部分在更普通的牛市里可能更划算，但本样本对它不利。
- **哨兵会在牛市误杀**：沪深300 动量短暂转负时会撤防御、踏空部分反弹（2025-26 有 33% 天数在防御）。这是降回撤的必然代价。
- **防御资产同样有风险**：国债/黄金并非无风险，极端情况（股债双杀）防御腿也可能回撤。
- **月频信号**：每月末定型，盘中不动；急跌当月内不调仓。
- 权威策略逻辑见 `docs/etf-mainline-rotation-strategy.md` 与 `docs/etf-trend-strategy-blueprint.md`；可与 `etf-mainline-leader-runner`、`etf-mainline-profit-runner`、`etf-rs90-top3` 并列对照。
