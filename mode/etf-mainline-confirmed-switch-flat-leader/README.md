# 连续确认强者替换非复利主线龙头

## 模式说明

该模式在 `etf-mainline-breadth-confirmed-flat-leader` 基础上，只改强者替换条件：新强者需要连续 2 次复核确认，并且 `anti_exhaustion_score` 领先当前持仓 0.06 后才替换。

它的收盘 `flatReturn` 略高于当前冠军，但优势只有约 0.1 个百分点，且次开 10bp 口径没有改善。因此本模式作为候选实验保留，不直接替代当前推荐模式。

## 推荐候选

`confirmed-switch-flat|anti_exhaustion_score|above60|4d|min8|top1|pg15%|dd6%|mainline_persist>=0.15|theme_breadth_above120>=0.50|theme_amount_power>=0.10|switch_margin=0.06|confirm2of2`

## 买卖规则

- 候选需满足 `above60`、`mainline_persist >= 0.15`、`theme_breadth_above120 >= 0.50`、`theme_amount_power >= 0.10`。
- 排序使用 `anti_exhaustion_score`。
- 每 4 个交易日复核一次，最小持有 8 个交易日。
- 新强者替换：需连续 2 次复核进入候选确认，并且强度领先当前持仓 `0.06`。
- 退出：跌出 Top1、跌破 MA120，或浮盈超过 15% 后从峰值回撤 6%。
- 最大持仓 1，满足最大持仓不超过 3；同一时点不会重复持有同主题 ETF。

## 风险

该模式的提升非常薄，且次开 10bp 执行口径没有高于当前冠军。单独从 2026H1 起跑时表现明显弱于全段路径，说明它对前序持仓路径有依赖。因此它更适合作为“减少误切”的候选实验，而不是当前推荐模式的直接替代。
