# 主线识别信号分析

区间 2025-01-02 → 2026-06-26｜55只跟踪池｜相对沪深300｜单腿周频(隔离信号质量)。

## A) RS90 上车滞后：选出主线时已从底部涨了多少

- 相对**60日低点**：中位 **57%**（25~75分位 34%~82%，最大 123%）
- 相对**90日低点**：中位 **74%**（25~75分位 62%~94%）
- 上车时已涨>20%(相对60日低)的比例：**83%**

> RS90 是 90 日相对强弱"变化率"，本质是趋势确认信号——它要等主线已经走出一段才点亮，所以中位已涨一两成才上车。好处是过滤掉假启动，代价是放弃鱼头。
