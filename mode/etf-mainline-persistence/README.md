# ETF 主线持续领先（persistence）研究 / 主线捕获诊断

针对你的关键质疑建立的诊断 + 实验包：
1. 现有模式**没把各段真·主升标的在一个模式里持有**，收益封顶；
2. **我们选主线的规则可能没实用性**——总 churn 进一周脉冲，错过持续数月的真主线。

点名的真主线：25 创新药、25 通信、25-26 中韩半导体、26 通信+科创芯片+半导体设备。底座（55 只跟踪池、a-stock-data、份额折算前复权、同主题去重、相对沪深300）与其它 mode 一致。

## 诊断结论（先看，这是本包的核心价值）

### 1) 你点名的主线 = 真·龙头（ground truth 验证通过）

| 子段 | 实现涨幅 Top |
|---|---|
| 2025H1 | **港股创新药 +62%**（榜首） |
| 2025H2 | **通信 +112%**（榜首）、创业板AI +87% |
| 2026H1 | **中韩半导体 +131%、全球芯片 +123%、半导体设备 +110%、科创芯片 +83%、通信 +63%** |

### 2) 真主线是「接力」的，不是「并存」的

创新药(25H1) → 通信(25H2) → 半导体(26H1)。当令窗口**不重叠**。"把各段主升标的同时持仓"是事后视角——现实里只能**轮动到当下那条**。这是"收益突破不了"的第一个根因，也是认知误区所在。

### 3) 现有 rs90 规则其实有实用性 —— 主线我们抓得到

每条主线在其当令窗口内的 rs90 横截面名次：

| 标的 | 当令窗口 | 窗口内中位名次 | ≤前3占比 |
|---|---|---:|---:|
| 港股创新药 | 2025H1 | **#2** | 56% |
| 通信 | 2025H2 | **#1** | 75% |
| 中韩半导体 | 2026H1 | **#1** | 100% |
| 科创芯片 | 2026H1 | #14 | 4% |
| 半导体设备 | 2026H1 | #11 | 18% |

- rs90 在每条主线当令窗口里都把它排到 **#1–#2**（中韩半导体 100% 的时间居首）。
- 科创芯片/半导体设备名次低，**不是漏抓**，而是同一"半导体大主题"里的**弱兄弟**——龙头中韩半导体(+131%) 已被排第1持有，且收益高于弱兄弟(+83%)，**持龙头本就更优**。
- 回测覆盖：rs90 N2/N3 **覆盖全部 5/5 点名主线家族**。

## 已验证失败的假设：persistence（保留为负面结论）

"锁定 RS 排名长期稳居前列者"听起来对，但回测更差：

| 配置 | 全段 | 回撤 | 真主线覆盖 |
|---|---:|---:|---:|
| **rs90 N2 均权** | **188%** | -24% | **5/5** |
| rs90 N3 均权 | 180% | -18% | 5/5 |
| persist N2 均权 | 61% | -27% | 3/5 |
| persist N3 均权 | 70% | -19% | 4/5 |
| persist N3 50/30/20 | 85% | -17% | 4/5 |

失败原因：真主线**并不总稳居单一指标前列**，持续性过滤既**滞后**（要等稳居前列N天）又**漏掉当令但非长青**的主线（如脉冲式启动的创新药）。

## 综合回答：为什么"突破不了"，以及怎么办

- **收益封顶的真因 = 接力切换的过渡损耗 + 多腿稀释，不是选不出主线。** rs90 已经把每条真主线排到 #1–#2 并持有。
- **想再突破只能更重仓"当下唯一龙头"**——但这正是已被证伪的"运气尖峰"（`etf-mainline-leader-runner` 的 rs90 80/20=348%、`etf-mainline-early-breakout` 的单腿 mom30=405%，换参数/加一腿即崩）。
- **可复现的现实最优 = rs90 N2(188%/-24%) 或 N3(180%/-18%)**，它本质就是"随主线接力、始终持有当下真龙头"的模式——也就是你想要的"把真主升标的放在一个模式里持有"，只是以**时间轮动**而非"同时持有"的形态实现。
- **唯一稳健的增强方向**：当龙头是无争议 #1（如中韩半导体 100% 居首）时，把权重向第1腿适度倾斜；但必须**设权重上限**（如最高 60–70%），既吃龙头红利又不掉进尖峰脆性。
