# ETF 主线指标大扫

本目录用于持续推进“继续回测所有可能指标”的目标。第一阶段先覆盖当前历史 K 线缓存中可稳定回测的指标，避免把只有实时值或资讯文本的数据硬塞进历史收益结论。

## 已回测指标族

- 动量：`mom20/30/40/60/90/120`、`abs13612`、短动量组合 `sprint*`。
- 相对强弱：`rs20/30/60/90/120`、`combo90`、RS 趋势质量、mom+RS 混合。
- 多周期一致性：短中长动量期限结构、曲率、加速度、均衡动量、长短周期一致性。
- 突破/位置：20/60/120 日突破、60/120 日区间位置。
- 均线/趋势：MA20/60/120 距离、均线多头结构、MA20/60 斜率。
- 量能/流动性：20/60 日量比、成交量代理、缩放量趋势。
- 成交额承接：`amount_ratio5/20/60`、成交额趋势、放量突破确认、价量合力、同主题成交额宽度。
- 波动：ATR 占比、20 日年化波动、低波趋势。
- K线结构：收盘位置、实体强弱、上下影线、跳空、ATR 收缩、VCP 窄幅蓄势突破、跳空动量确认。
- 路径质量：上涨日比例、趋势效率、收益/波动、收益/下行波动、局部回撤调整动量。
- 技术指标近似：RSI14、BOLL %B、MACD histogram。
- 复合主线：`mainline_core/mainline_early/mainline_persist`。
- 阶段新高持有：20/60/120 日新高突破后趋势持有。
- 主题代理：跟踪池内同主题 ETF 的宽度、强动量比例、突破比例、主题平均动量。
- 持续性主线：强势榜 Top 持续性、主题 Top 持续性、新晋主线分数。
- 横截面排名：趋势质量分位、动量分位、主题宽度分位、排名跃迁与排名质量。
- 本轮新增代理：成交额加权成本线、量价承接、均线回踩转强、波动状态切换、主题宽度/成交额宽度加速度。

## 当前结论

加入趋势寿命/反过热扰动后，当前收盘口径最佳候选微幅变为：

`factor|anti_exhaustion_score|above60|3d|100%`

| 指标 | 数值 |
|---|---:|
| 收益 | +564.8% |
| 年化 | +265.0% |
| 最大回撤 | -21.6% |
| 交易 | 67 |
| 最大持仓 | 1 |
| 次开 10bp | +473.0% |

它的本质仍是趋势质量因子族，而不是全新范式：在 `mom30_trend_quality_smooth` 基础上，对短期过热/耗竭做轻微惩罚。提升只有 `+1.9` 个百分点，不能把它理解成参数已被“精确调中”，更合理的结论是“30 日动量 + 趋势质量 + 轻度反过热”这一族稳定有效。

核心趋势质量公式仍是：

```text
mom30_trend_quality_smooth =
  mom30
+ 0.15 * max(MA20/MA60 - 1, 0)
+ 0.15 * max(收盘/MA60 - 1, 0)
- 0.15 * ATR20/收盘
```

这相当于在 `mom30` 基础上增加趋势斜率和 MA60 上方质量，并惩罚高波动。它不是标的定制，但仍然属于单仓主线追随模式，收益集中度需要继续关注。

当前次开 10bp 鲁棒口径的最佳候选为：

`factor|gap_momentum_score|above60|3d|100%`

| 指标 | 数值 |
|---|---:|
| 收益 | +559.3% |
| 最大回撤 | -21.6% |
| 交易 | 65 |
| 次开 10bp | +473.0% |

它是在趋势质量基础上加入跳空、实体和上影线惩罚。它与 `pvt_confirm_score`、`anti_exhaustion_score` 的次开 10bp 基本同档，所以更应理解为“执行确认/轻度反过热扰动有效”，而不是全新范式。

## 多主线 Runner 复测

已新增“最多 3 个不同主题”的 Runner 模式，并修复开仓循环中的同主题重复问题。修复后，Runner 会在每次新增仓位前重新检查主题占用，避免同时持有例如港股创新药和港股创新药(广发)这类同主题标的。

进一步修复了执行层细节：当天退出某主题后，当天不再买入同一主题内的其他 ETF，避免“卖出港股创新药后同日买入港股创新药(广发)”这类无意义主题内切换。

进一步加入多周期一致性后，当前最佳 Runner 更新为：

`runner|multi_mom_quality_score|above120|5d|base`

| 指标 | 数值 |
|---|---:|
| 收益 | +167.9% |
| 最大回撤 | -18.9% |
| 交易 | 45 |
| 最大持仓 | 3 |
| 均仓 | 2.89 |
| 次开 10bp | +158.5% |

结论：多周期质量改善了 Runner，但仍没有突破单仓最佳。它降低了对单一标的的依赖，也能同时持有多个不同主题；但 Top3 中仍会混入黄金、银行、资源、宽泛科技等“强但非核心主线”的方向，稀释通信、芯片、半导体设备这类主升段收益。因此下一步不应继续只调 Runner 参数，而应引入成分股宽度、成分股资金宽度、板块新高宽度来判断“是否是真主线”。

## 多周期一致性复测

本轮新增不只是 `mom90` 这类单周期动量，而是检查短中长周期之间的结构：

- `multi_period_consistency`: 20/60/120 日动量同向且站上 MA60；
- `multi_mom_quality_score`: 多周期动量 + 趋势质量 + 波动惩罚；
- `balanced_momentum_score`: 20/60/120 日均衡动量，避免只追极短冲刺；
- `acceleration_curve_score`: 20 日强于 60/120 日的加速曲率；
- `term_structure_slope/curve`: 动量期限结构斜率与弯曲程度。

结果：

| 指标 | 收益 | 次开10bp | 观察 |
|---|---:|---:|---|
| `balanced_momentum_score` | +536.9% | +461.0% | 单仓较强，但低于趋势质量最佳。 |
| `acceleration_curve_score` | +489.2% | +422.8% | 可捕捉加速段，但换手与噪声更高。 |
| `multi_period_consistency` | +243.9% | +230.2% | 过度要求长短周期一致会滞后。 |
| `runner|multi_mom_quality_score` | +167.9% | +158.5% | 当前多主线 Runner 最佳。 |

结论：多周期数据对“组合持仓/Runner”有增量，对单仓主排序没有超过趋势质量。主线捕捉不能只要求所有周期都好，因为真正主升常常先由短中周期加速确认，长周期确认反而滞后。

## 本轮新增指标复测

为继续推进“除了 mom/rs 之外”的搜索，本轮新增了一批仍可用历史 K 线验证的主线代理：

- `amount_price_dist20/60`: 当前价格相对近 20/60 日成交额加权成本线的位置；
- `amount_cost_reclaim_score`: 30 日动量 + 站回成交额成本线 + 成交额趋势；
- `volume_price_absorption_score`: 放量后收盘位置较强、上影线不过重；
- `vcp_breakout_score`: ATR 收缩后突破，叠加成交额趋势和上影线惩罚；
- `ma_pullback_reclaim_score`: 上升趋势中回踩 MA20/MA60 后重新转强；
- `volatility_regime_shift_score`: 波动从收缩到扩张的状态切换；
- `theme_width_accel*` / `theme_breadth_accel_score`: 同主题 ETF 宽度的 5/10 日加速度；
- `theme_money_rotation_score`: 同主题成交额确认与成交额加速度；
- `mainline_expansion_score`: 趋势质量 + 主题宽度 + 主题宽度加速度。

结果：

| 指标 | 收益 | 次开10bp | 观察 |
|---|---:|---:|---|
| `vcp_breakout_score` | +447.7% | +392.4% | 新增项最佳，但仍弱于趋势质量。 |
| `volatility_regime_shift_score` | +420.3% | +393.8% | 可以解释波动切换，不能做主排序。 |
| `amount_cost_reclaim_score` | +353.5% | +303.0% | 成交额成本线独立排序偏弱。 |
| `theme_breadth_accel_score` | +270.3% | +229.4% | ETF 池内主题宽度加速度噪声大。 |
| `runner|mainline_expansion_score` | +150.2% | +152.5% | Runner 有一定改善，但低于多周期 Runner。 |

结论：这轮新增指标没有突破现有最佳，反而强化了一个判断：只用 ETF 自身 K 线和同主题 ETF 代理继续雕花，已经很难解决“选出真正主线”的问题。下一阶段必须接入项目内置的板块新高宽度、成分股宽度和成分股资金宽度。

## 路径质量复测

本轮新增路径质量/趋势顺滑度指标：

- `drawdown_adjusted_mom30/60`: 动量 + 阶段回撤；
- `path_quality_score`: 趋势质量 + 顺滑度确认。

结果：

| 指标 | 收益 | 次开10bp | 观察 |
|---|---:|---:|---|
| `path_quality_score` | +373.0% | +328.8% | 明显弱于趋势质量。 |

## 成交额因子复测

本轮已把 a-stock-data `mootdx_kline` 返回的 `amount` 纳入缓存和因子计算。结果显示，ETF 自身成交额放大能提供确认信息，但不能单独承担主线选择：

- 量能/流动性族最佳：`factor|price_amount_power|above120|10d|85%/10%/5%`
- 收盘口径：`+218.6%`
- 次开 10bp：`+156.5%`
- 结论：不超过 `mom30` 鲁棒基准 `+384.0%`，应作为“主线宽度/资金宽度”的确认项，而不是核心排序项。
