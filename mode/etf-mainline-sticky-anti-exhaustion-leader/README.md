# 黏性过热衰竭主线龙头

当前进攻型主线龙头模式的改进版。以 `anti_exhaustion_score` 选择主线龙头，并加入最小持有期、换手门槛和 Top2 黏性退出，减少排名噪声交易。相比黏性缺口量价版本，次开 + 10bp 收益更高，最大回撤更低。

## 推荐候选

推荐配置：`sticky-anti|anti_exhaustion_score|above60|3d|min6|sw0.04|top2`

买卖规则：

- ETF 池沿用主线研究池 55 只；
- 入场：满足 `above60`，按 `anti_exhaustion_score` 排名取 Top1；
- 调仓：每 3 个交易日检查一次；
- 黏性规则：最小持有 6 个交易日；
- 强者替换：新标的分数至少高出当前持仓 0.04 才替换；
- 退出：跌破 MA120，或持仓跌出 Top2；
- 仓位：单腿 100%，最大持仓 1，天然不超过最大持仓 3；
- 成交验证：重点看次开 + 10bp 成本口径。

## 稳健性复查

围绕推荐参数做局部精扫后，`rebalance=3`、`top2` 退出、`min_hold=4~6`、`switch_margin=0.035~0.060` 的多组相邻参数均得到同一组核心结果：收盘 `+599.2%`、最大回撤 `-23.6%`、次开 10bp `+529.8%`。这说明推荐配置不是单点尖峰。

另一个低回撤邻近版本为 `rebalance=4`、`top1`、`min_hold=9~11`，次开 10bp 约 `+509.0%`、最大回撤约 `-21.8%`；但已有风控过滤版本提供更清晰的低回撤路线。

## 重要风险

- 该模式仍是单腿龙头模式，收益集中度高。
- Top2 黏性退出会延迟卖出，若主线突然失效，可能扩大回撤。
- 回测区间为 2025-01-02 至 2026-06-26，需要继续前向跟踪。
- 因子仍来自 ETF 自身 K 线，实盘应结合板块宽度、成分新高和资金流确认。
