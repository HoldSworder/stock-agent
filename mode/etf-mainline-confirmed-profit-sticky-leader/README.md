# 主线确认盈利保护黏性龙头

在“盈利保护黏性主线龙头”基础上加入历史可回测的主线持续性确认门槛。核心排序仍然是 `anti_exhaustion_score`，`mainline_persist` 只做候选过滤，避免单只 ETF 短期过强但主线延续不足时误入。

这一步更接近“真正主线”的处理：不让主线指标替代价格趋势，而是要求趋势龙头同时具备一定主线持续性。

## 推荐候选

推荐配置：`confirmed-profit-sticky|anti_exhaustion_score|above60|3d|min4|sw0.035|top2|pg25%|dd8%|mainline_persist>=0.02`

买卖规则：

- ETF 池沿用主线研究池 55 只；
- 入场门槛：满足 `above60`，且 `mainline_persist >= 0.02`；
- 排名：在门槛内按 `anti_exhaustion_score` 取 Top1；
- 调仓：每 3 个交易日检查一次；
- 黏性规则：最小持有 4 个交易日；
- 强者替换：新标的分数至少高出当前持仓 0.035 才替换；
- 常规退出：跌破 MA120，或持仓跌出 Top2；
- 盈利保护：单笔持仓浮盈超过 25% 后，如从持仓峰值回撤 8%，在复核点退出；
- 仓位：单腿 100%，最大持仓 1，天然不超过最大持仓 3；
- 同主题约束：单腿持仓不会同时买入同主题重复标的；
- 成交验证：重点看次开 + 10bp 成本口径。

## 稳健性复查

围绕推荐参数做局部精扫后，`mainline_persist >= 0.02~0.05`、`min_hold=4~6`、`switch_margin=0.035~0.040`、`protect_gain=25%~30%`、`protect_dd=8%` 的多组相邻参数均得到同一组核心结果：收盘 `+658.0%`、最大回撤 `-23.6%`、次开 10bp `+595.0%`。这说明结果不是单点尖峰。

分段复核显示，2025H1 / 2025H2 / 2026H1 三段均为正收益，次开 10bp 分别约 `+31.8%`、`+131.2%`、`+122.0%`。

门槛曲线中，`mainline_persist >= 0.15` 的次开 10bp 可到 `+655.4%`，但最大回撤恶化到 `-28.8%`，且高门槛区波动明显，暂不作为推荐。当前推荐的 `0.02` 位于更稳定的平台。

本地 SQLite 的 `board_newhigh_snapshots` 当前只有 `2026-06-26` 一天快照，不能直接用于 2025-2026 全窗口回测；本模式使用的是因子面板内可随历史 K 线重建的 `mainline_persist`，避免把单日快照变成未来函数。

## 重要风险

- 该模式仍是单腿龙头模式，收益高度集中在全球芯片、半导体设备、通信、卫星等少数主线标的。
- `mainline_persist` 是历史价格/趋势衍生的主线确认，不等同于真实板块宽度数据库；实盘仍应叠加板块新高宽度、成交额跃迁和资金流。
- 盈利保护会提前兑现部分强趋势，若主线只是正常震荡，可能被洗出后再买回。
- 回测区间为 2025-01-02 至 2026-06-26，需要继续前向跟踪。
