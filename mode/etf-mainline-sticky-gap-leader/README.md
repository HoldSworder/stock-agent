# 黏性缺口量价主线龙头

进攻型执行优化模式。以 `gap_momentum_score` 选择主线龙头，但加入最小持有期和换手门槛，减少排名微小变化造成的无效调仓。目标是提高次开 + 成本口径，而不是单纯降低回撤。

## 推荐候选

推荐配置：`sticky-gap|gap_momentum_score|above60|3d|min6|sw0.04`

买卖规则：

- ETF 池沿用主线研究池 55 只；
- 入场：满足 `above60`，按 `gap_momentum_score` 排名取 Top1；
- 调仓：每 3 个交易日检查一次；
- 黏性规则：最小持有 6 个交易日；
- 强者替换：新标的分数至少高出当前持仓 0.04 才替换；
- 退出：跌破 MA120，或持仓跌出 Top3；
- 仓位：单腿 100%，最大持仓 1，天然不超过最大持仓 3；
- 成交验证：重点看次开 + 10bp 成本口径。

## 重要风险

- 最大回撤扩大到约 -25.8%，明显高于过热衰竭/执行共识模式的约 -21.6%。
- 黏性规则会延迟卖出，适合强主线延续期，不适合主线突然崩塌的环境。
- 该模式仍是单腿龙头模式，收益集中度高，实盘需配合仓位上限、主线宽度和市场状态过滤。
