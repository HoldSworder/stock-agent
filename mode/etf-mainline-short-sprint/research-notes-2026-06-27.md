# ETF 短周期主线冲刺研究笔记

## 本轮尝试

上一版 `etf-mainline-early-breakout` 的核心强项是 `mom30 + above120 + Top1 + 5 日调仓`，回测收益约 `+420.1%`，最大回撤约 `-16.5%`。本轮没有继续引入 RS90，而是沿着短周期主线突破思路，测试更短的调仓节奏和相邻动量窗口。

搜索维度：

- 动量窗口: `mom20/mom25/mom30/mom35/mom40/mom45/mom50/mom55/mom60`，以及少量短周期合成分数。
- 趋势过滤: 无过滤、MA60 之上、MA120 之上。
- 调仓周期: 1/3/5/10 个交易日。
- 组合权重: Top1、Top2、Top3 的若干通用权重。
- 持仓限制: 最大 3，同主题最多 1 只。

## 结论

最值得记录的候选是：

`wrot-keep|mom30|above120|3d|100%|ma120`

它可以理解为：仍然使用 `mom30` 识别短期主线，但把检查周期从 5 日缩短到 3 日，只持有最强一条主线，并要求标的仍在 MA120 上方。

全段复核结果：

| 指标 | 数值 |
|---|---:|
| 收益 | +468.3% |
| 年化 | +227.9% |
| 最大回撤 | -21.6% |
| 交易次数 | 85 |
| 实际最大持仓 | 1 |
| 2025 收益 | +195.9% |
| 2026 截至 2026-06-26 收益 | +88.1% |
| 次开 10bp 收益 | +384.0% |

## 与上一版的关系

这不是“组合收益”的另一个口径，而是一个新的交易模式回测结果。它与上一版相比，是同一 ETF 池、同一回测区间下的策略规则替换：

- 上一版: `mom30 + above120 + Top1 + 5 日调仓`，更稳，回撤较小。
- 本版: `mom30 + above120 + Top1 + 3 日调仓`，更快切换，收益更高，但回撤和交易摩擦更大。

因此可以把它定位为“短周期冲刺模式”：适合主线扩散很快、强弱切换频繁的阶段；如果市场进入震荡或成本显著上升，它可能不如 5 日版舒服。

## 不过拟合检查

- 没有按单标的定制规则；港股创新药、半导体、通信、卫星等都只是由同一 `mom30` 规则自然选出。
- 摘要按主题聚合收益集中度，`港股创新药` 和 `港股创新药(广发)` 不再作为两个独立收益来源展示。
- 同收益变体中，优先选择 `above120` 和 `keep`，避免用无趋势过滤或频繁重置权重的版本美化结果。
- 保留成本敏感性：次日开盘成交、单边 10bp 后收益降至 `+384.0%`，说明收益仍强，但已经低于收盘 0bp 的 `+468.3%`，不能忽略滑点。
- 收益仍然集中在少数强主线上：全球芯片、卫星、通信、半导体设备贡献很高。这是主线冲刺模式的天然特征，也意味着回撤会更尖锐。

## 风险提示

本模式相比上一版更激进。它超过了当前收盘口径基准，但不是稳健性全面胜出：最大回撤更大、交易更多、对成交价更敏感。实盘前更适合先作为观察/模拟组合，而不是直接替代低频版本。
