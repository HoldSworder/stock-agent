# 后续执行计划：找到一套过关的中线买入规则

Status: 待执行
Blocked by: `.scratch/provable-advice/` 第一阶段已完成

术语见 `CONTEXT.md`。方法决策见 `docs/adr/0005-战法资料库与考试边界.md`。裁决原文见 `issues/17`、`issues/18`（上一目录）。

## 目标

在不偷看、不扫参、不把未过关买点塞进今日动作的前提下，从公开战法里找出**结构不同**的买入假设，先历史筛选、再最多三套记前向记录。过关之前，系统继续只做风险提示和研究展示。

## 不在范围内

- 定版任何买入规则、改今日动作为买入清单（须双门过关且你指定占用前向名额之后）
- 估值 / 财报买卖规则（排在第一批考试之后）
- 涨停类、RSI 短线
- 把几把位置尺子加成一个「更准」的分数
- 自动开考、自动占用前向三套、按历史成绩自动换规则

## 执行顺序

`issues/` 编号即顺序。未下令开考之前，03 只允许把引擎写好待命。

1. 战法资料库（能入库、能分类、能标明来源与证据强弱）
2. 第一批写成可考试规则（默认不参加筛选）
3. 历史筛选引擎（你下令才跑）
4. 位置同向总览（灯可增减，不进建议链，不抢 1–3 的跑道）
5. 估值资料（第一批考完之后才开工）

## 过关之后才允许的事

历史筛选未淘汰 → 你指定占用最多三套前向名额 → 页面只比成绩、不喊当天买哪只 → 走出样本且信号级优于随机 → 才可进入今日动作。
