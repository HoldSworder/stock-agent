# 0005 · 战法资料库与考试边界

日期：2026-09-16
状态：已采纳

## 背景

第一阶段证明：当时的买入规则过不了走出样本考试，ETF 盯盘买点相对随机也没有优势。下一步不是再调那 20 套同源参数，而是公开收集结构不同的战法，用同一套考试方法筛选。

## 决策

1. **资料库只研究、不自动下单。** 收录不代表有效。新条目默认只入库。
2. **开考、占用前向名额、替换家族代表版本，都必须由使用者下令。** 程序不得按历史成绩自动换人。
3. **指数成绩只淘汰逻辑；ETF 成绩才判断能不能执行。** 两张不得加总。
4. **位置尺子结合看（共振），仍不是规则。** 总览只答齐不齐。
5. **估值是后续。** 不插入第一批。

## 备选与不选

**闭门只改现有 20 套。** 已证明同源会一起失效。

**网上自动抓战法并重排。** 会变成不停调参。

**研究页列出当天该买哪只。** 等于换个地方喊未过关买点。

## 后果

- 资料库和今日动作之间有硬闸。
- 第一批名单与考试淘汰条件以 `.scratch/buy-rule-search/spec.md` 为准。
- 与 ADR 0002 一致：一旦某套被定版，至少一个完整季度不改参数。
