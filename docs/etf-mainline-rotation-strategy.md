# ETF 主线轮动策略 · 可执行模式与回测方法

> 本文档沉淀 2026-06 一轮回测打磨后**最终锁定的可执行交易模式**，是 `etf-trend-strategy-blueprint.md`（策略逻辑蓝本）的落地版：明确到每一条买卖规则、参数取值、回测方法，可直接照做、可复现。

---

## 0. 一句话定位

> **主线门禁挑对赛道 → 金叉进场，错过金叉才在主线内做平台放量续涨 → Supertrend 出场。不按相对强弱排名主动换仓。**
> 系统只负责"待在当下最强的主线里"并执行纪律，不预测顶底、不追求精确抄底。

> **⚠️ 机械性边界**：本文档的回测是 **100% 机械**的——每笔买/卖/轮换都是确定性指标规则，无人工/AI 判断。它对应蓝本的"机械核心"。蓝本完整系统之上还有一层**预警层**（跌停潮/背离 → 收紧止损、减半仓），交给 AI 研判 + 人工，**未纳入本回测**。即：回测是不含人工护盘的下限版本，实盘会在其上叠加预警层。

## 1. 完整买卖规则

一笔买入必须 **同时满足"主线门禁"和"入场信号"**，缺一不可。

```
能买入 = 主线门禁通过  AND  入场信号
入 场 = 日线 MACD 金叉。追涨只在错过金叉后，并且只做主线内的平台放量续涨
出 场 = Supertrend(10,3) 翻空
轮 换 = 持仓走坏、腾出位子时，由新的主线补上。不按相对强弱排名主动换仓
止 损 = 单笔不超过 5%
```

### 1.1 主线门禁（决定"是不是主线、碰不碰"）
板块同时满足：
- **趋势中**：收盘价 > MA60
- **RS 守领先**：RS ≥ 自身 60 日 RS 高点 × 0.97
  （RS = 板块收盘 ÷ 沪深300收盘；"守领先"= 仍稳在近 3 个月相对强度的高位，即持续跑赢大盘）

> 门禁是慢信号、要确定性。先有主线再谈买点。空位由新的主线补上，不按相对强弱排名主动替换。

### 1.2 入场信号（决定"何时买"）
- **日线 MACD 金叉**是主入场：DIF 上穿 DEA（参数 12/26/9）。
- **追涨**只作为错过金叉后的补救，并且只做主线内的平台放量续涨：收盘 ≥ 20 日新高，昨收 < 昨日 20 日高，成交量 > 1.3×5 日均量。乖离超过 3 倍 ATR 不追。
- 单笔止损不超过 5%。

### 1.3 出场
- **Supertrend(10, 3)**：ATR 用 Wilder 平滑。收盘对当根最终轨道判断翻向。上升段里昨天的下轨不高于今天的下轨时，不再因此把出场推迟。
- 单笔止损不超过 5%。锁顶只留乖离至少 18% 并且出现第一根下跌。牛市不做大面积逃顶。

### 1.4 换仓
持仓走坏、腾出位子时，由新的主线补上。不按相对强弱排名主动换仓。

### 1.5 空位怎么补
空位由已经通过主线门禁、并且走出金叉（或错过金叉后的主线内平台放量续涨）的标的补上。不按相对强弱排名主动替换。

早期版本曾按相对强弱排名换仓。现行规则不这么做。

### 1.6 仓位（不强推单一档，按可承受回撤自选）
- 持有 **N 只**（N=1/2/3），**等权**，每只 1/N 仓位。
- 出场或被轮换后资金回到现金，等待下一个合格信号补位；无合格候选时该格留现金（可阶段性空仓）。
- 收益与回撤近似线性绑定，**抓真主线 ⇄ 大回撤焊死**，按可承受回撤选档（完整跟踪池实测，见 §3）：
  - **进攻**：满仓2只 +190%/−24% 或 满仓3只 +178%/−22%（3只更分散、回撤略低）
  - **均衡**：3只各28%留16% +145%/−19% ｜ 3只各25%留25% +125%/−18%
  - **稳健**：3只各22%留34% +106%/−16%
  - 满仓1只 +172%/−35%：收益不差但回撤陡、最颠，不推荐。

## 2. 回测方法（可复现）

| 项 | 设定 |
|---|---|
| **数据源** | a-stock-data sidecar `mootdx_kline`（`http://<NAS>:9119`，通达信本地 TCP，不封 IP，~0.3s/只，比 NAS `/api/kline` 快 ~20×；为同一份 mootdx 数据，已验证两源逐日一致） |
| **复权** | 生产日线已按采纳 6 复权。只有跳空超过该品种当日涨跌幅极限才进折算判断。±10% 用 12%，±20% 不用 12%。跨境和商品 ETF 不用百分比推断。成交量只在送转、份额折算时缩放，现金分红不放大量。 |
| **区间** | 2025-01-02 → 2026-06-26（**连续一段**，让盈利跨年复利，不拆年） |
| **基准/RS分母** | 沪深300（510300） |
| **标的池** | **ETF 模块完整跟踪池（`/api/etf/pool`，55 只）**（见 §5） |
| **入场** | 金叉是主入场。追涨只在主线内做平台放量续涨，乖离超过 3 倍 ATR 不追。单笔止损不超过 5%。 |
| **成交价** | 收盘确认的信号从下一交易日开盘成交。开盘封死、买不到，则当天不成交，顺延到下一根能成交的开盘。信号当天的涨跌不计入成绩。 |
| **账本** | 初始 1.0；等权 N 格各 1/N×当前权益；现金不计息；单格买入额 = min(权益×1/N, 可用现金) |
| **回撤** | 按每日权益曲线峰值计最大回撤 |
| **年化** | (期末净值)^(1/年数) − 1，年数 = 交易日数 / 244 |

### 2.1 指标口径
- **MACD**：EMA12 − EMA26 = DIF；DEA = EMA9(DIF)；金叉 = DIF 上穿 DEA。
- **Supertrend(10,3)**：ATR 用 Wilder 平滑。收盘对当根最终轨道判断翻向。上升段里昨天的下轨不高于今天的下轨时，不再因此把出场推迟。
- 年化和斜率都用 244 个交易日。
- **RS**：板块收盘 ÷ 沪深300收盘。
- **RS守领先**（门禁，自相对）：RS ≥ max(近60日RS) × 0.97。
- **换仓**：不按相对强弱排名主动换仓。持仓走坏、腾出位子时，由新的主线补上。
- **复权**：与现行日线同一条。只有跳空超过该品种当日涨跌幅极限才进折算判断。±10% 用 12%，±20% 不用 12%。跨境和商品 ETF 不用百分比推断。成交量只在送转、份额折算时缩放，现金分红不放大量。
- **斜率/R²**：对最近 20 日 log 收盘做最小二乘线性回归，斜率年化（×244）。

### 2.2 执行顺序（每个交易日盘后）
1. 先处理出场：持仓中任意一只 ST 翻空 → 清仓该格。
2. 计算候选池：未持有，并且主线门禁通过，并且走出金叉（或错过金叉后的主线内平台放量续涨）。不按相对强弱排名。
3. 换仓：持仓走坏、腾出位子时，由新的主线补上。不按相对强弱排名主动换仓。
4. 补空位：有空格则补上已经通过主线门禁、并且走出金叉（或错过金叉后的主线内平台放量续涨）的标的。无合格候选则该格留现金。
5. 记录当日权益、更新最大回撤。

## 6. 局限与诚实提醒

1. **样本是两个超级趋势年**：2025/2026 是 A 股罕见的连续主升行情，+100% 量级年化是"强行情 + 强赛道池"叠出来的，**不是常态**；换大熊市或风格剧变会大幅打折。
2. **浮盈占比**：满仓档总收益里有相当部分是期末未实现浮盈（半导体设备 +27%、通信 等仍持有中），若回吐总收益会下来。
3. **抓真主线 ⇄ 大回撤焊死**：满仓档真实回撤 ~22~24%；压到 ~18% 收益降到 +125%（留25%现金）。收益与回撤近似线性。
4. **复权**：生产日线已按采纳 6 复权。只有跳空超过该品种当日涨跌幅极限才进折算判断。成交量只在送转、份额折算时缩放，现金分红不放大量。
5. **早期版本按相对强弱排名换仓**。现行规则不按相对强弱排名主动换仓。
6. **同族板块相关性风险**（待优化，跟踪池尤甚）：那次历史回测里，光伏/电池/储能或两格电网可能被同一波回调一起打到止损（见 §4 的 2025-11、2026-03）。跟踪池重复标的多会加重。
7. **主线判定是相对自身**：`RS守领先`（门禁）是 RS 跟自身比。换仓不按相对强弱排名主动替换。
8. **多腿趋势捕获打折**（结构性）：锯齿磨涨的板块（如电池）会因 ST 被反复洗，吃不满整波——回撤保护与捕获率不可兼得。
9. **数据源**：默认 a-stock-data sidecar `mootdx_kline`（不封 IP、快），与 NAS `/api/kline` 同源一致；需关注 sidecar 与国内网络稳定性。
