## 0. 目标

停挖后用纸面/旁路验证 Loop24 在**向前滚动**的样本外行为：信号是否可执行、记账是否干净、近窗伤是否恶化到需降权。  
**不是**自动交易；**不是** commit 现网。

## 1. 策略钉死（克隆 Loop24）

| 项 | 值 |
|---|---|
| 池 | 510300 / 159915 / 518880 / 511010 |
| 信号 | 月末最后一个交易日收盘；每只 25D 对数价 OLS；`score = slope × R²` |
| 持有 | score>0 的 Top2 等权 50/50；仅 1 正→Top1 100%；全≤0→100% 511010 |
| 成交 | **次月开盘**（信号 close → 次日/次月开盘价） |
| 成本 | 单边 5bps（按权重变动绝对值） |
| 并列 | 代码序 510300 > 159915 > 518880 > 511010；优先续持上月 |
| 脚本参考 | `backend/src/scripts/mainline.loop24.jq11Top2Ew.ts`（未 commit；影子可复制到本目录） |

禁止：改窗长/去 R²/剔金/改 Top3/叠均线或 Loop18 硬 AND。

| 项 | 值 |

## 4. 披露红灯（只披露，不自动改规则）

每月末写明：

1. **金日占比**（滚动自影子起点）：连续两月 >40% → 群内提示「路径偏金」，不自动降权  
2. **相对 BH 近 63 交易日**（约一季）超额 < −8pp → 提示「近窗伤再现」  
3. **滚动 MDD** 深于 −28% → 提示「控撤劣化于回测主窗」  

红灯只触发复盘，**不**改参数、**不**自动切 Loop11/18。

## 5. 升格 commit / 现网门槛（须用户拍板）

影子满 **≥3 个完整调仓月** 且同时满足，才可提交「升格讨论」卡片（仍须用户点头）：

| 门槛 | 要求 |
|---|---|
| A 可执行 | 信号日与次月开盘均有行情；无连续缺数 |
| B 路径 | 金日占比 ≤40%（影子窗）；300 持仓不全为 0 |
| C 控撤 | 影子窗滚动 MDD 不深于 −28% |
| D 相对 | 影子窗相对 510300 BH 总收益 ≥ −3pp（允许略落后，不允许崩） |

任一门不过 → 继续影子或改挂对照，**禁止**为过门改规则。  
通过 → 三人复盘后请用户拍板是否 commit 入库 / 旁路现网；默认仍不接实盘仓位链。
