# 宽基 25 日斜率 · 结果

**判定：OOS-PASS**。

2020-01-01 到 2026-10-14 相对沪深300买入持有记 **OOS-PASS**。回撤更浅 +13.58pp（要至少浅 8 个百分点），年化差 +11.06pp（不能少过 3 个百分点）。换成另一只 47 次，持有最多的是黄金（34.39%）。2024 起的修复段只说明、不参与这两条。不改现在正在用的规则。

## 这轮测了什么

只拿四只：沪深300（510300）、创业板（159915）、黄金（518880）、五年国债（511010）。每月最后一个交易日收盘，对每只取最近 25 个交易日的收盘价，用对数价格对时间（从 0 到 24）做一条直线。得分 = 这条直线的斜率 × 它贴合价格的程度。不把斜率换算成年化。次月第一个交易日开盘全部换成得分最高的那一只。

四只得分都不大于 0 时，不再去拿「没那么差」的那只，改拿五年国债。有任意一只得分大于 0，就拿最高的那只，国债也可以因为自己得分最高而被选中。并列时继续拿已经拿着的那只。

没有再加趋势开关、波动缩放、风险平价、杠杆，也没有再加别的过滤。没有去试别的窗口长度或别的名单。买卖按单边万分之五扣费。同一只续拿不扣费。信号只用到月末已经收盘的价格，次月开盘才成交。

新浪日线是不复权价。程序只补上大幅折算，现金分红和票息没有加回去。仓库里没有五年国债的总回报序列，所以没有改用别的数据源。国债这类靠派息的品种，价格涨跌会低于连同票息的持有回报。

敏感性（只说明，不重跑）：债腿被低估之后，它的得分偏低，临界时更不容易选中国债；拿着国债的那些天，净值里也少了票息。回撤因此更容易被算得偏深，年化在拿债的日子里也偏低。这会让「过线」更难，不是更好看。本轮不假设一个每年票息再加回去重算，因为那个数字没有事先钉死。

事先定好、看完数字不改的两条（都相对同一窗口的沪深300买入持有，窗口从 2020-01-01 到末端）：

1. 策略的最大回撤要比沪深300至少浅 **8 个百分点**。
2. 策略年化不低于沪深300年化减 **3 个百分点**。同时写出总收益差了多少。

下面这些只写出来，不过不过都不改上面的判定：2024-01-01 到末端这段里，2024年9月24日到年底的修复，加上同一套规则自动找出的其它修复，并在一起之后策略相对沪深300差多少；每只拿了多少天、换成另一只几次。四只各拿四分之一、以及单拿某一只，也只作对照。
