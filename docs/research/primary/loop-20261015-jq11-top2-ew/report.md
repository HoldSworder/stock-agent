# 宽基 25 日斜率×R² · Top2 等权 · 结果

**判定：OOS-PASS**。

2020-01-01 到 2026-10-14 相对沪深300买入持有记 **OOS-PASS**。回撤更浅 +21.90pp（要至少浅 8 个百分点），年化差 +10.36pp（不能少过 3 个百分点）。成分替换 68 次，双持月份占比 73.17%，持有最多的是黄金（28.77%）。相对 Loop11（Top1）：回撤差 +8.32pp、年化差 -0.70pp（只对照消融，不过第二道线）。2024 起的修复段只说明、不参与这两条。不改现在正在用的规则。

## 这轮测了什么

本轮为 **Loop11 的单变量持有规则消融**。宇宙钉死四只：沪深300（510300）、创业板（159915）、黄金（518880）、五年国债（511010）。每月最后一个交易日收盘，对每只取最近 25 个交易日的收盘价，用对数价格对时间（从 0 到 24）做一条直线。得分 = 这条直线的斜率 × 它贴合价格的程度（**score = slope × R²**，公式、池、窗长完全与 Loop11 一致）。

**本轮唯一变量 — 次月开盘持有规则**：
- 在 **score > 0** 的标的中，按 score 取 **Top2 50/50 等权**；
- 若仅有 **1** 只标的 score > 0，则 **100% 持有该标的**（Top1）；
- 若 **全员 score ≤ 0**，则 **100% 切换至五年国债（511010）**。

没有再加趋势开关、波动缩放、风险平价、杠杆，也没有加任何别的过滤。买卖按单边万分之五扣费（按权重变动绝对值计费）。同权重续持不扣费。信号只用到月末已经收盘的价格，次月开盘成交。

新浪日线是不复权价。程序只补上大幅折算，现金分红和票息没有加回去。仓库里没有五年国债的总回报序列，所以没有改用别的数据源。国债这类靠派息的品种，价格涨跌会低于连同票息的持有回报。

数据末端：2026-10-14。四只都有行情的交易日 2398 天，沪深300自己的交易日 2399 天。
- 沪深300（510300）：2016-11-24 ~ 2026-10-14，2399 根。

事先定好、看完数字不改的两条（都相对同一窗口的沪深300买入持有，窗口从 2020-01-01 到末端）：

1. 策略的最大回撤要比沪深300至少浅 **8 个百分点**。
2. 策略年化不低于沪深300年化减 **3 个百分点**。同时写出总收益差了多少。

下面这些只写出来，不过不过都不改上面的判定：2024-01-01 到末端这段里，2024年9月24日到年底的修复，加上同一套规则自动找出的其它修复，并在一起之后策略相对沪深300差多少；相对 Loop11 的消融对照；每只拿了多少天、换成另一只几次。四只各拿四分之一、以及单拿某一只，也只作对照。
