## 这轮测了什么

进攻腿只拿沪深300（510300），停车腿五年国债（511010）。**消融口径**：仅当 MA120 > MA250 持 510300，否则持 511010。已去掉 Loop17 的急跌退出与修复入场。

日频用当日收盘算 MA，次日开盘换仓。买卖按单边万分之五扣费。同一只续拿不扣费。没有扫均线窗，没有加回急跌/回补，没有叠 20D 动量 / RSRS / 黄金 / 纳指 / 主题选股。

新浪日线是不复权价。程序只补上大幅折算，现金分红和票息没有加回去。空仓换成 511010（与前几轮债停车口径一致）。国债这类靠派息的品种，价格涨跌会低于连同票息的持有回报。年化交易日口径 244（本轮无波动门槛）。

数据末端：2026-10-14。两只都有行情的交易日 2399 天，沪深300自己的交易日 2399 天。
- 沪深300（510300）：2016-11-24 ~ 2026-10-14，2399 根。
- 五年国债（511010）：2016-11-24 ~ 2026-10-14，2399 根。

事先定好、看完数字不改的两条（都相对同一窗口的沪深300买入持有，窗口从 2020-01-01 到末端）：

1. 策略的最大回撤要比沪深300至少浅 **8 个百分点**。
2. 策略年化不低于沪深300年化减 **3 个百分点**。同时写出总收益差了多少。
